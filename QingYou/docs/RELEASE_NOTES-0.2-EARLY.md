# 轻右 0.2.0 · 第二版预览

这次更新围绕 Finder 的使用习惯，重做导航、工具箱和文件操作反馈。

## 新功能与体验

- 全新薄荷色品牌视觉、柔和背景、分色工具卡片和薄荷色 Q 丝带图标；随系统切换明暗。
- 独立品牌导航配合原生可收起分栏、统一工具栏与搜索框。
- 首页交互插画、选中背景滑动、按钮按压和卡片悬停轻抬，尊重减少动态效果设置。
- 全局搜索工具、菜单功能、设置和文件模板。
- 工具箱支持本地文件拖放与文件选择，按整批文件类型启用适用工具。
- 日常精简、图文工作、全部功能三套菜单预设，保留其他个人配置。
- 默认直接显示在 Finder 右键菜单中，省去「轻右」中间层；仍可手动开启收纳模式。
- Finder 菜单补充系统图标与选择数量，混选目录时隐藏不适用的媒体和校验工具。
- 剪贴板没有文件时禁用粘贴，剪切状态下明确提示「移到此处」。
- 批量重命名采用原生表格、后台延迟合并预览、变化筛选和重置；过期预览不会覆盖最新输入。
- 轻量完成面板不抢焦点，提供显示结果与撤销；支持关闭提示，鼠标停留时暂停自动收起。
- 主窗口结果栏、真实执行中的任务标题、操作记录筛选、工具栏撤销入口。
- 改名、移动与撤销后，工具箱内已选文件路径同步更新。
- 页面、排序、拖放、悬停和提示采用短动画，尊重「减少动态效果」与「降低透明度」。

## 兼容与验证

0.1 配置直接兼容，新增完成提示默认开启。62 项测试通过：48 项核心与媒体测试，14 项应用集成测试；覆盖异步拖放、配置迁移、类型判断、改名撤销后的选择更新与任务队列。
最低系统目标 macOS 13；当前迭代构建 arm64 本机版本。实际设备验证范围见 [验证记录](VERIFICATION.md)。

开发构建使用 ad-hoc 本地签名，尚未获得 Developer ID 签名或苹果公证。Intel 与较旧 macOS 仍需实机测试。
本轮不生成安装包、不上传；dist/ 中旧安装包不代表当前开发版本。

## 本地交互迭代（2026-10-23）

- 新建模板文件直接生成「未命名.扩展名」，冲突自动编号；默认在 Finder 中选中，可按回车使用系统改名。
- 复制路径、文件名、终端路径、Markdown 链接及剪切标记均不显示成功面板，保留本地操作记录。
- 新建成功不重复提示；错误仍有明确说明。可选的自动打开文件偏好继续生效。
- 默认右键直接显示功能；当前开发机设置已同步，其他旧用户的个人配置不被强制重置。
- 图标改为深青底与薄荷色 Q 丝带。当前只做本地开发、构建和安装，不生成或上传发布包。

- 通用设置新增「登录时自动启动」，首次默认申请开启，手动关闭后不再自动开启，采用系统登录项状态；待批准可前往系统设置，也可取消申请。登录启动不弹出主窗口，普通打开行为保持不变。真实登录后的启动行为仍待验证。

## 默认启动与名称编辑（2026-10-24）

- 本机登录项注册成功，状态显示已开启；默认只申请一次，失败也不反复申请。
- 增加新建后直接编辑文件名偏好与辅助功能授权入口。确认 Finder 处于前台、单选的完整 URL 与新文件身份一致后，尝试点击 Finder 自己的改名菜单；切换应用、选择不明确或超时均放弃自动操作。
- 没有授权时静默保留选中，可按回车改名；选择自动打开文件时优先打开。当前尚未获得辅助功能授权，完整自动改名流程仍待实测。

## 精简菜单与 WPS 文档（2026-10-24）

- 新建菜单统一为「类型（.扩展名）」并加上文件类型小图标；新增真实 DOC、XLS、PPT 空白模板，和现有 DOCX、XLSX、PPTX 一起供 WPS 使用。
- 拷贝路径直接显示为顶层选项；移除复制信息分组及额外路径格式入口。
- 收起常用目录、批量重命名、项目创建、指定应用打开与 SHA-256 的菜单及主界面入口。保留终端、文件传输、图片、PDF 等工具。
- 新建办公文档默认优先使用已安装的 WPS，仅设置当前新文件的打开关联，支持在文件模板设置中关闭。
- 配置升级保留自定义模板、名称、关闭状态和其他偏好；新增格式只补齐一次。
- 当前共 65 项测试通过，六种办公模板通过结构检查；本轮仍不打包、不上传。

## PDF 工作台与文件夹终端（2026-10-24）

- 单选 PDF 直接显示「拆分 PDF…」，多选 PDF 直接显示「合并 PDF…」；菜单收纳模式下也保留这两个顶层入口。
- 拆分支持连续范围和多个范围组合，每组输出一份 PDF，提供原文与结果双栏预览。默认按原名和页码命名，也可为每份结果填写名称；输入框焦点自动切换到对应预览，实时显示保存名称。
- 合并提供原生缩略图顺序列表、带插入位置的拖动与箭头调整、完整结果预览；点选文件名或卡片即可查看原文。输出保存在当前文件夹，保留原件并避开重名。合并后调用已有 Finder 名称编辑流程。
- 使用系统 PDFKit 页面缩略图、缩放和适合窗口；无效范围就地说明，导出期间避免重复提交或关闭。
- 终端入口改用系统文件夹终端服务，避免将目录作为执行对象打开；服务调用通过替身测试，实际 Terminal 提示仍需桌面验证。
- Finder 地址识别兼容 URL、文件 URL 字符串和完整路径。自动名称编辑仍需当前安装版本获得辅助功能授权，尚未完成实机确认。
- 当前 76 项测试通过；本轮继续只安装本地开发版，不打包、不上传。

## 窗口快捷键修复（2026-10-24）

- 补充「文件 → 关闭窗口」及 ⌘W，输入框有焦点时也能关闭当前窗口；⌘Q 仍用于退出程序。
- 关闭某个窗口时保留其他窗口的菜单与快捷键，全部关闭后继续驻留菜单栏。
- Finder 图标视图不暴露所选文件地址时，额外核对单选名称与路径栏完整地址，满足全部条件才尝试自动命名。
- 77 项测试通过，主窗口与 PDF 窗口的 ⌘W 已实机验证。自动命名新增兼容处理仍待当前开发版重新授权后实测。
