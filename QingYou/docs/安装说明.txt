轻右 QingYou 0.2.2 · 开发预览
文档更新：2026-10-29

当前状态
本包是 0.2.2 开发预览，供另一台 Mac 安装测试；不是已公证的正式发行版。
本包主程序与 Finder 扩展均包含 Apple Silicon + Intel 两种架构。
最低目标为 macOS 13；PDF 压缩需要 13.4 或更新系统。
Intel 与更早 macOS 尚待实际设备验证。

安装与启用
1. 打开 DMG，把 QingYou.app 拖到“应用程序”；ZIP 则先解压。
2. 从“应用程序”打开轻右，无需安装 Xcode、Swift、Office 或 WPS。
3. 在首页点击“管理扩展”，按系统引导启用“轻右 Finder 扩展”。
4. 回到 Finder 右击文件、文件夹或空白处，直接选择功能。
   “轻右”父级子菜单是可选设置，默认关闭。

使用
• 新建文件直接生成“未命名.扩展名”，冲突自动编号，Finder 中按 Return 改名。
• “粘贴为文件”把剪贴板文字／图片保存为 TXT／PNG，⌥ 可选 Markdown。
• 图片任务收进“图片处理”，PDF 合并／拆分／压缩／整理／导出收进“PDF 处理”。
• 工具打开独立窗口并保持后台身份；主动打开主窗口时才在 Dock 显示。
• PDF 合并与拆分支持预览，拆分按页码范围生成多份结果。
• 图片和 PDF 另存结果，保留原件；默认保存到右键所在目录。
• 新顺序列表请先用上下箭头；拖动尚未完成桌面验证。
• ⌘W 关闭当前窗口，⌘Q 退出。长任务可取消，退出前等待处理结束。

系统访问
处理文稿、桌面等目录时，macOS 可能询问文件夹访问；由你按需要选择。
自动进入名称编辑需要可选的辅助功能授权，已在本机实测；未授权时按 Return 改名。
重新授权后可先正常退出再启动轻右，保证系统授权对当前进程生效。
本地开发签名变化后系统可能重新确认权限，旧开关不代表新构建已授权。
首次默认申请登录启动一次；手动关闭后不再自动开启。

菜单没有出现
确认扩展启用及当前目录在生效范围内，检查“右键菜单”功能开关。
在首页刷新状态、重新打开 Finder 窗口；也检查其他扩展是否造成重复菜单。
主程序工具箱可独立使用。图片与 PDF 入口在空白处会随后选择所需文件。

分发与兼容
当前构建使用 ad-hoc 签名，尚未完成 Developer ID 签名及苹果公证。
通过网络传输后，macOS 可能提示无法验证开发者。
请先确认文件来源和校验值；确认可信后按系统提示自行决定是否打开。
Apple 官方说明：https://support.apple.com/zh-cn/102445
不要关闭系统安全检查；若提示文件已损坏或无法加载扩展，记录提示并反馈。
已在 Apple Silicon / macOS 26.3 本地验证，Intel 与更早系统仍待实机覆盖。
完整功能、验证范围与限制见源码仓库 README.md 和 docs/VERIFICATION.md。

卸载
退出轻右，将应用移到废纸篓，或在工程中运行 scripts/uninstall.sh。
脚本保留设置、自定义模板、操作记录和工作文件。
本地数据位于 ~/Library/Application Support/QingYou/，可自行备份后清理。
