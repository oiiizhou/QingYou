# 轻右 0.2.1 · 菜单更清爽，任务留在后台

2026-10-28 · 预览版 · build 5

这次更新解决右键功能过长、执行任务时跳出 Dock 图标，以及升级后 Finder 扩展偶尔不加载的问题。已有功能开关、菜单顺序和自定义模板继续保留。

## 下载与安装

- 推荐下载 **QingYou-0.2.1.dmg**；**QingYou-0.2.1.zip** 是同一应用的备用包，两者均含 Apple Silicon 与 Intel 架构。
- 打开 DMG，将 QingYou.app 拖入「应用程序」。升级前先退出旧版，再替换同一位置的应用。
- 启动后在首页点「管理扩展」，按系统引导启用 Finder 扩展。
- **Source code** 是源码归档；普通用户选择上面的应用安装包。
- 最低 macOS 13；PDF 压缩需要 macOS 13.4 及以上。

## 改进

### 更短的右键菜单

- 调整图片、图片信息、图片合成 PDF 统一收进 **图片处理**。
- 合并、拆分、压缩、整理页面、导出图片、提取文字统一收进 **PDF 处理**，各操作只展开一层。
- 新建文件、拷贝路径、打开终端等常用入口继续直接显示。
- 图片与 PDF 分类在文件夹空白处也可使用，再通过系统选择器补充文件。
- 保留功能开关、顺序和可选的「轻右」总子菜单；分类不会绕过收纳偏好。

### 安静地完成任务

- 右键启动和独立图片／PDF 窗口保持后台身份，不再主动加入 Dock。
- 用户主动打开主窗口时显示 Dock 图标；关闭主窗口后回到后台，其他任务窗口可以继续使用。
- 通过明确的 Finder 启动参数判断来源，移除依靠延时决定是否显示主窗口的逻辑。
- 保留系统 ⌘W 关闭当前窗口，图片与 PDF 输入框获得焦点时同样可用。

### 更可靠的更新与分发

- 本地安装脚本先注销并停止旧扩展，再注册新版，避免误结束刚加载的新进程。
- 只恢复此前已启用的扩展，不覆盖用户主动关闭的选择。
- 新增安装包校验：实际解压 ZIP、只读挂载 DMG，逐文件核对应用、双架构、签名、模板、许可和 SHA-256；CI 同样执行。
- README 同步版本、直接下载入口和实际验证范围。

## 验证

- 98 项本地自动化检查通过：57 项核心与媒体、24 项应用集成、17 项工作台。
- 主程序与 Finder 扩展均完成 arm64 + x86_64 构建，DMG／ZIP 内容校验通过。
- Apple Silicon / macOS 26.3 安装后扩展正常运行；后台图片、PDF 拆分和页面整理窗口的 ⌘W 已实测。
- 用户重新授权后，TXT 与 PPTX 新建请求实际进入 Finder 名称编辑。未授权时保留选中状态，可按 Return 改名。

以上为本地验证；云端构建状态见仓库 Actions。详细记录见 [VERIFICATION.md](VERIFICATION.md)。

## 预览版限制

- 当前采用 **ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证**。网络下载后可能出现来源检查；核对文件来源与 SHA256SUMS.txt 后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)决定是否打开。
- 开发签名变化可能使系统重新确认文件夹或辅助功能权限；辅助功能只用于可选的自动改名。
- Intel、较早 macOS 及另一台 Mac 的网络下载安装仍需实机验证。
- 新图片／页面列表拖动仍需补测，请先用上下箭头；终端服务提示与更多系统语言也需覆盖。
- PDF 重写不保证保留书签、交互表单或数字签名；压缩不保证体积更小。处理结果另存，保留原件。
