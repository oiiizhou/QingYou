# 文件工具窗口设计（2026-10-26）

模式：Operate。沿用 DESIGN.md 的 macOS 系统字体、系统蓝、灰白平面、细边框与真实窗口控件，不更换视觉系统。

用户从 Finder 选择文件或空白处右键开始，直接打开对应任务窗口，不要求先进入轻右主页。

## 入口与行为

| 任务 | 参数／顺序区 | 预览与完成方式 |
| --- | --- | --- |
| 粘贴为文件 | 自动识别剪贴板文字或图片 | 文字落为 TXT、图片落为 PNG；静默保存并交给 Finder 命名，已有文件仍使用原粘贴命令 |
| 调整图片 | 最大宽高、百分比、自定义宽高；保持比例、不放大；格式、质量、旋转、翻转、去除位置 | 原图与预计结果，显示原始和目标像素；多张按同一规则处理，保存副本 |
| 图片信息 | 文件、拍摄、相机、色彩和位置字段 | 图片预览；缺失数据明确说明，GPS 仅使用文件内记录，地图由用户主动打开 |
| 图片合并为 PDF | 原生列表拖动／箭头排序、添加／移除；纸张、方向、边距 | PDFKit 页预览，导出到当前目录 |
| PDF 压缩 | 系统图片优化三种组合 | 原文与优化结果、实际大小对比；不假定体积必然减小，不把文本页栅格化 |
| PDF 页面整理 | 页面缩略图、拖动／箭头排序、旋转、删除、插入 PDF | 结果预览，保留原有文字和矢量，另存副本 |
| PDF 导出 | 页码范围、PNG／JPEG、分辨率，或文字提取与无文字页 OCR | 页预览；图片放到独立结果文件夹，文字保存为 TXT |

## 窗口结构

Intent：用户要就近完成一次文件处理，像使用系统“预览”的工具面板。

Hierarchy：原文／结果是主视觉，参数在左侧，确认操作固定在底部。标题 20–21 pt、正文 13 pt、辅助文字 11–12 pt。

Palette／Depth／Surfaces：复用现有语义色与原生 controlBackgroundColor；区块用 1 pt 边界或 Divider，无装饰阴影、渐变、卡片套卡片。

Spacing：参数内边距 20 pt、同组 8–12 pt；底栏固定，较小窗口中参数和列表滚动。使用 Button、Picker、TextField、List、NSOpenPanel 和 PDFKit，不仿制窗口交通灯。

## 状态和数据约束

- 参数无效时行内说明并禁止导出；后台预览采用代次与取消令牌，旧结果不能覆盖新设置。
- 长任务提供进度与取消；先暂存、后提交，同名保留两份。取消或失败不覆盖原件，不留下半套输出。
- 运行时关闭窗口会先取消任务再关闭，标准 ⌘W、Esc 和回车行为保留。
- 时间分别标明文件时间和 EXIF 拍摄时间；拍摄时区缺失时不推测。无 GPS 的图片不展示猜测位置，不自动调用在线地理编码。
- PDF 系统图片优化依赖 macOS 13.4+；动态／多页图片不静默丢帧，要求先导出单张。沿用原格式支持 PNG／JPEG／HEIC／TIFF，其余源格式及混合批次在确认前要求明确选择输出格式，不静默回退。
- PDF 页面图片使用“导出序号-原第N页”命名，非递增输入范围也能在 Finder 名称排序中保留输入顺序。结果预览不是授权或格式兼容性的替代证据。

## 验收

检查真实图片的方向、比例、透明背景、元数据；PDF 的页面数量、顺序、旋转、文字保持、范围输出和同名保护；独立剪贴板测试文字／图片落盘且不改变剪贴板。所有新窗口检查明暗、最小窗口、焦点、无效输入、取消和文件选择。
