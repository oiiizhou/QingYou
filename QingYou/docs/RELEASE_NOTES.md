# 轻右 0.2.0 · 开发预览

更新日期：2026-10-26。当前为源码及本地开发构建，尚未发布与本文同步的正式安装包。版本号仍为 0.2.0，未为未执行的发布创建标签。

## 这次更新

### 从 Finder 就近处理

- 功能默认直接显示在右键中，可在设置中选择收纳；正常菜单移除末尾设置入口。
- 合并、拆分、压缩、页面整理以及图片任务可从空白处开始，不适用的选区通过系统选择器补充。
- 文字或图片“粘贴为文件”，生成 TXT／PNG；按住 ⌥ 选择 Markdown。已有文件继续使用系统粘贴。
- 文件模板补齐 DOC／DOCX、XLS／XLSX、PPT／PPTX，统一图标与名称，检测到 WPS 时可优先打开。

### 图片工作台

- 最大宽高、百分比、自定义像素；锁定比例时宽高联动，默认不放大小图。
- 原图与结果预览、格式与质量、旋转／翻转、去除位置元数据，另存副本。
- 原格式受限时明确要求选择输出格式，不静默回退；混合批次提前检查。
- 查看实际 EXIF、相机、镜头、时间、色彩和 GPS；缺失信息不推测，地图仅主动打开。
- 多图生成 PDF，支持箭头排序、纸张、方向、边距和逐页预览。

### PDF 工作台

- 保留合并及多范围拆分、原文／结果预览、自定义拆分名称。
- 使用 macOS 13.4+ 的图片优化压缩，显示实际大小变化，保留文字与矢量。
- 页面重排、旋转、删除、插入其他 PDF，再另存结果。
- 按范围导出 PNG／JPEG、指定 DPI；文件名前缀保留输入顺序，后缀标注原页码。
- 提取可选择文字，必要时用本机 OCR 补充无文字层页面。

### 原生界面与交互

- 灰白画布、系统蓝、细边界和系统字体；真实窗口控制与明暗外观。
- 独立任务窗口，无需先进入主页；错误就地说明，长任务支持进度与取消。
- ⌘W 沿系统响应链关闭当前窗口，输入框聚焦时同样有效。
- 新输出先暂存后提交，同名保留两份；取消或失败回滚本次输出。
- 登录启动首次默认申请一次；手动关闭后保留选择，登录启动不弹主窗口。

## 本地验证

97 项自动化检查通过：57 项核心与媒体、23 项集成、17 项新工作台。另实测 Finder 新入口、图片真实像素、PDF 页序／旋转／导出、简单无文字层扫描页 OCR、窗口快捷键及本地安装。详细范围见 [VERIFICATION.md](VERIFICATION.md)。

## 已知限制

新页面／图片列表拖动尚未通过桌面实测，请先用上下箭头。自动名称编辑完整交互、终端权限提示、Intel 与较早 macOS、大型文件及更多辅助功能组合仍需验证。PDF 重写不保证保留书签、交互表单或数字签名；压缩不保证文件更小。

当前 ad-hoc 签名会随构建变化，系统可能重新确认文件夹或辅助功能权限。Developer ID 签名、公证及另一台 Mac 的网络下载安装尚未完成。
