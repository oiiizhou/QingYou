# 轻右 0.2.2 · 右键更快，操作更顺手

2026-10-29 · 预览版 · build 7

修复 Finder 右键菜单每次展开时的明显等待。菜单样式、图片／PDF 分类和已有操作保持原有习惯。

## 这次改进

- **图标更轻**：原先部分系统类型图标携带最高 2048 像素的整套图像；现在仅保留菜单所需的 16／32 像素位图，支持普通与 Retina 屏幕，保留文档类型颜色。
- **固定内容复用**：缓存文档图标和 SF Symbols，配置在初始化或变更通知时刷新，减少每次右键的重复工作。
- **菜单传输更少**：完整选区保留在扩展，Finder 只传回轻量标识，点击操作后再生成请求，避免大量文件重复传输。
- **剪贴板判断更轻**：每次菜单只读取一次类型声明，保留文件、文字、图片、Markdown 和剪切状态的适用性。
- **增加 8 项回归检查**：覆盖图标体积与颜色、菜单代理回调、选区顺序、剪贴板状态、配置刷新和损坏配置恢复。

## 响应对比

Apple Silicon / macOS 26.3，同机、自建空文件夹，各连续右键 6 次：

| 指标 | 优化前 | 本地优化构建 |
| --- | ---: | ---: |
| 菜单出现时间，中位数 | 247.8 ms | 76.0 ms |
| 第一轮右键 | 301.4 ms | 182.2 ms |

中位数等待减少约 **69%**。时间从验收程序投递右键事件开始测量，包含 Finder 和其他已加载组件；不代表所有设备、目录或物理鼠标均有相同结果。性能测量来自先行本地 build 6，本发布 build 7 同步版本信息并重新构建通用包。完整记录见 [VERIFICATION.md](VERIFICATION.md)。

## 下载与安装

- 推荐 **QingYou-0.2.2.dmg**；**QingYou-0.2.2.zip** 为同一应用的备用包，均包含 Apple Silicon 与 Intel 架构。
- 先退出旧版，打开 DMG，将 QingYou.app 替换到原来的应用位置；再启动并确认 Finder 扩展启用。
- macOS 13 及以上；PDF 压缩需要 13.4 及以上。**Source code** 为源码归档，普通用户请选择应用安装包。
- 附件同时提供 **SHA256SUMS.txt** 与中文 **INSTALL.txt**。
